**O-7 Closed(2026-08-19) — 원인 확정 불가, 재조사 불필요.** 근거는 팀장 SQL Editor 실측
(`scripts/sql/o7_child_id_diag.sql` Q1~Q6 + `scripts/sql/o7_parent_scope.sql` Q7~Q11)이다.
전체 규모는 `reading_sessions` **140행** · 완독 **86행** · 자녀 **10명** · 부모 **10명**이고,
완독 86 × 50 = **4,300**이 실제 포인트 합계와 일치한다(**총량 보존**).
① **부모:자녀 = 1:1**이라 `getActiveChild`에 선택 여지가 없다 — 오선택이 **구조적으로 불가능**.
② 두 자녀의 `parent_id`가 **다르다**(Q10 `same_parent=false`) — RLS 경계상 앱 완독 경로로
포인트가 **계정을 넘을 수 없다**. ③ 따라서 **"+50이 −50으로 이동"이라는 해석은 기각**하고,
합계 0은 **우연**이며 서로 **무관한 두 사건**으로 본다. ④ 현재 코드는 `child_id` **단일 출처**
(`d2237d3`, 2026-07-01)라 2회 독립 해소 구조는 소멸했다. ⑤ 영향은 **개발용 계정 2개 한정,
실사용자 0명**.
**미해결로 남기는 것**: ±50이 언제·무엇으로 생겼는지는 **특정하지 못했다**(팀장도 수동 변경
여부 기억 없음 — **확인 불가**). **포인트 값은 보정하지 않고 유지한다** — 실사용자 영향이
없고 그 차이가 **유일하게 남은 흔적**이기 때문이다. 상세는 ADR-0059 §Open questions
「O-7 (최종 상태)」. ★ Closed→Reopen→Closed 이력이 있으므로 **근거 없이 상태만 인용하지 말 것.**

목록에 비활성 도서를 **그대로 표시한다** ③ 다만 **다시 읽기(뷰어 진입)는 차단한다**
④ 차단 시 아이가 이해할 수 있는 **안내 문구를 노출한다**(예: "이 책은 지금 쉬는 중이에요").
**채택 근거**: 3~7세 대상에서 "읽은 책이 사라지는 것"은 혼란·상실감을 준다 / 목록에서 숨기면
총점과 목록 개수가 어긋나 오히려 버그처럼 보인다 / 다시 읽기를 허용하면 중복 정리가 무의미해진다.

발생하지 않는다.** 상세는 ADR-0059 §Open questions 「O-8」.

→ **인수인계에 자녀 1명 수치가 전체값처럼 옮겨진 것이 원인이다.**
현재 전체는 **140행 / 완독 86행**이며 부모별 내역은 `9f59a9ac` 56/52 · `d98b4767` 45/17 ·
`9c4f345f` 32/16 · `a1ee7c92` 4/1 · `cb70783f` 2/0 · `0b4291b1` 1/0
(`o7_parent_scope.sql` Q11, `orphan_session_rows` 전부 0). 정리 삭제분을 되돌리면
2,433 + 45 + 32 + 4 + 2 + 1 로 과거 수치와도 어긋나지 않는다.

**재발 방지 규칙(교체)**
- 수치를 정본화할 때 **측정 범위(전체 / 자녀 1명 / 부모 1명)를 반드시 함께 적는다.**
  **범위 없는 수치는 정본으로 인정하지 않는다.**
- 두 시점의 수치를 비교할 때는 **그 사이에 정리·삭제 커밋이 있었는지 먼저 확인한다.**

**O-6 Closed(2026-08-18)** — 테스트 성격 자녀 6명(전원 `points` 0)을 **삭제하지 않고 현상
유지**로 종결했다. 화면 동작 무영향(`getActiveChild` = `created_at ASC LIMIT 1`) · 삭제는
`reading_sessions` FK 연쇄로 비가역 · 포인트 0이라 집계 오염 없음. **작업 큐에서 제외**한다.
**ADR-0059 실행 순서 4단계도 마감** — 2026-08-18 팀장 브라우저 육안 확인에서 `/mypage`
"읽는 중" **3권**(930 아님)·degraded 안내 없음, `/home` 회귀 없음이 확인됐다.
**O-3 Closed(2026-08-18)** — `degraded` 표시 문구는 **현행 유지**로 종결하고, 다듬기만
디자인 전면(**큐 D**)으로 이관했다. **"표시 없이 로그만" 선택지는 기각** — 로그만 남기면
사용자가 잘린 수치를 사실로 믿게 되어 본 트랙이 없앤 문제로 되돌아간다. 디자인 단계에서도
**표시 여부는 바꾸지 않고 표현만** 다듬는다.
★ 용어: 이 문서에서 **"마이페이지 P1"이라는 묶음 명칭은 더 이상 쓰지 않는다**(ADR-0059
§Status 용어 주석). 마이페이지 관련 작업은 **O-7·O-8 개별 항목**(큐 B·C)이다.
