## 3. 잔여 Open 3건과 처리 시점

### O-7 — **Reopen**. 적립 대상 `child_id` 1건. **8/23~25**

- **실측(팀장 `children.points` 직접 조회)**: 키키주니어 **+50** · 초은우 **−50** ·
  우허니 0 · kikikiki 0 · 나머지 6명 전원 0. **차이 합계 = 0**(정확히 상쇄).
- **적립 로직 자체는 정상** — 10명 중 8명 차이 0. 쓰기 경로는
  `lib/book/rewards.ts:112-117` **한 곳뿐**이고 마이그레이션에 points 트리거·함수 **0건**.
- **총량 보존** — 새거나 증발한 것이 아니다. 남은 의문은 **"완독 1건이 어느 자녀에게
  적립됐는가"** 하나다. `child_id` 결정 경로는 **아직 추적하지 않았다.**
- ★ **포인트 값 수동 보정 금지.** 원인 미확정 상태에서 수치를 맞추면 재발 감지 단서가
  소멸한다. 이 금지는 O-7 조사 착수 전까지 유효하다.

### O-8 — 정책 판단. **8/23~25**, 표시 방식만 검토

비활성 도서 완독분 포인트 잔존(키키주니어 900P·35% / 초은우 350P / 우허니 350P).
**포인트 회수는 검토 대상이 아니다** — 아이가 실제로 읽은 기록이다.
증상은 "포인트는 있는데 '읽은 책' 목록에는 없는" 상태(목록이 비활성 도서를 뺀다).
**데이터 변경 없음.**

### O-9 — GDL 파서 점검. **9월 첫주**. 베타 전 코드 변경 금지

`sync_gdl.py`의 저자·삽화가 파싱 누락 가능성이 유력하나 **원인 미확정**(코드 미확인).
라이선스 위반으로 **단정할 수 없다**(원본 미제공 정보를 표시할 의무 없음,
`attribution_text`는 NOT NULL이라 어트리뷰션 자체는 전 도서 존재).
파서를 고치면 **464권 재동기화**가 뒤따른다.

**베타(8/31) 차단 항목은 0건이다.**

## 6. 이번 세션 학습 2건

1. **화면 수치만으로 원인 계층을 단정하지 말 것.** O-7을 "화면 표시 계층의 자녀 매핑
   문제"로 분류해 Closed 처리했으나, `children.points`를 **화면 경유 없이 직접 조회**하자
   **DB 저장값 자체가 어긋나 있었다**. 같은 날 Reopen됐다. 표시 계층 문제라는 판정은
   표시를 우회한 조회로 확인한 뒤에만 성립한다.
2. **수치를 정본화하기 전 실측 대조를 강제할 것.** "Ruth 잔재 443행"은 세션 노트 1곳에만
   있던 근거 없는 수치인데 검산 없이 일정 정본에 올랐고, 그 결과 **보존 결정 자산을 삭제
   대상으로 지시하는 작업지시서**까지 발행됐다. 8/18 "17권 32면"(실측 18권 33면)에 이은
   **같은 유형의 세 번째 재발**이다. 어느 개인의 과실이 아니라 **검산 절차의 부재**다 —
   수치가 정본에 들어가기 전에 출처가 실측인지 대화 전달분인지 구분하는 단계가 필요하다.
   (ADR-0056 `:237`이 이미 같은 함정을 박제해 뒀다: "총계 검산은 배분 오류를 잡지 못한다.")
