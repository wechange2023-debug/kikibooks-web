# ADR-0065: 단어카드·퀴즈 파일럿 — 기록 없이 완독 직후에만 붙인다

## Context

### 1. 실측 기반 (E-0 조사, 2026-08-20 · 읽기 전용)

본 절의 수치는 전부 **E-0 조사 보고의 실측값**이며 추정이 아니다.

#### 1.1 본문 텍스트는 `book_text` 테이블에 있다

`book_audio`가 아니라 별도 `book_text`가 원천이다. 두 테이블 모두
`supabase/migrations/`에 DDL이 없어(마이그레이션은 `profiles·children·books·
reading_sessions·favorites·child_badges` 6개만 정의) 라이브 DB introspect로 확인했다.

컬럼: `id, book_id, page_index(0-based), text, blocks(jsonb), source, updated_at, image_url`

총 9,496행 / 고유 860권. 활성 도서 기준 커버리지:

| 출처 | active | `book_text` 보유 | `text` 있음 | 커버리지 |
|---|---|---|---|---|
| Book Dash | 190 | 190 | 190 | **100%** |
| ASb | 527 | 527 | 527 | **100%** |
| Bloom | 141 | 141 | 141 | **100%** |
| **GDL** | 464 | **0** | **0** | **0%** |
| **합계** | **1,322** | **858** | **858** | **64.9%** |

**GDL 464권(활성의 35%)은 본문 텍스트가 전무하다.** 이것이 본 파일럿의 최대 제약이며
D2가 이를 처리한다.

`source` 분포(행 기준): `manifest_txt_v1` 6,899 · `pdf_harvest_v2_orderfix` 2,128 ·
`html_scene_json_v1` 469. **`blocks` jsonb는 2,128행(pdf_harvest 계열)에만 존재**하므로
단어 추출이 `blocks` 구조를 전제해서는 안 된다 — `text`만 신뢰한다.

텍스트 품질은 정제된 영어 산문이다. 표본 1,000행 기준 페이지당 **중앙값 15단어**
(평균 20.1 · 최대 186), **0단어 페이지 0건**. 예: `"I have a friend. She lives in my house."`

#### 1.2 단어 단위 타이밍 마크가 전량 존재한다 (미활용 자산 아님 — 이미 리더가 쓴다)

`book_audio.marks_path`가 **10,476행 전량 NOT NULL**이다.
`scripts/tts_pilot/generate_tts.py:14`·`:167-176`이 AWS Polly
`SpeechMarkTypes=["word"]`로 생성한 **단어별 타임스탬프**이며, `:100`에서 UTF-8 바이트
오프셋을 원문 기준으로 보정한다.

중요한 것은 **이 자산의 소비 경로가 이미 구현돼 있다**는 점이다:

- `lib/book/audio-manifest.ts:55`·`:73` — 매니페스트가 페이지별 `marksUrl`을 이미 노출
- `components/book/audio-reader.tsx:123-145` — `parseMarks()` line-delimited JSON 파서
- `components/book/highlighted-text.tsx:22-31` — `WordMark { time, value, start, end }` 타입
- `lib/book/highlight-config.ts:14` — `HIGHLIGHT_UNIT = 'word'`

따라서 D4의 "단어 발음 재생"은 **신규 파이프라인이 아니라 기존 자산의 재조합**이다.
추가 TTS 비용 0.

`book_audio` 보이스 분포: `danielle` page 9,042 + cover 860 / `Ruth` page 530 + cover 44
(레거시 잔존, 리더는 `danielle`만 사용).

#### 1.3 기존 보상 체계의 제약

`lib/book/rewards.ts`의 `awardCompletionRewards(childId)`가 유일한 적립 지점이다.

- `:64` `POINTS_PER_COMPLETION = 50` · `:67` `FIRST_COMPLETION_BADGE = 'first_completion'`
  (배지 코드 **1종뿐**)
- `:112-117` `children.points` **SELECT-then-UPDATE** — `:41` 주석이 비원자성을 명시적으로
  인정하고 "베타 수용"으로 처리
- `:1` `import 'server-only'` + `'use server'` **의도적 미부여**(ADR-0018 Amendment #1
  `:12-16`) — 클라이언트 직접 호출 표면이 **구조적으로 없다**

이 설계는 "호출자가 RLS로 검증한 `childId`를 넘긴다"는 계약(`:28-32`)에 안전성을 의존한다.
**클라이언트가 퀴즈 점수를 보내 적립하는 형태는 이 계약과 정면 충돌한다.**

#### 1.4 O-10 — 기록을 붙이면 상속되는 결함

`reading_sessions`에 **UNIQUE 제약이 없다**
(`supabase/migrations/001_initial_schema.sql:121-134` — 인덱스 3개 전부 평범한 INDEX).

ADR-0059 O-10 `:651-670`이 기록한 귀결: 동시 요청 시 미완료 2행 INSERT 가능 → 완독
UPDATE가 `LIMIT` 없이 갱신 → 2행 동시 완독 → `.maybeSingle()` 실패 →
**`awardCompletionRewards` 미호출 → 완독은 남고 포인트 0**.

판정은 "실사용자 재발 가능, 베타 비차단, 큐 J로 이연, **베타 전 코드 변경 금지**"다.

**퀴즈 결과를 `reading_sessions` 확장으로 저장하면 이 결함을 그대로 상속한다**(같은 행이
2개 생기므로 점수도 중복·유실). 신규 테이블로 가면 UNIQUE를 올바르게 걸 수 있으나,
O-10 미해소 상태에서 자녀 단위 쓰기 경로를 하나 더 늘리는 것 자체가 위험 증가다.

**→ D1(무기록)이 이 딜레마를 회피하는 선택이다.**

#### 1.5 UI 자산 현황

- `components/ui/`에 프리미티브가 `button.tsx`·`section-header.tsx` **2개뿐**.
  Card·Modal·Dialog 없음
- 카드 컴포넌트는 이미 **3벌 중복**(`ShowcaseBookCard` / `BookCoverCard` /
  `LibraryBookCard`) — `app/showcase/showcase-book-card.tsx:13-17`이 이 중복을 기록
- **드래그 사용 사례 0건.** `onDrag`·`draggable`·dnd 라이브러리 전무
- 외부 애니메이션 라이브러리 0개 — `components/book/celebrate-rewards.tsx:29`가
  `framer-motion`·`canvas-confetti` 미도입을 명시. count-up은 `requestAnimationFrame` 자체 구현
- 스와이프는 자체 구현 선례 있음(`components/book/asb-reader.tsx:265-282` native
  `touchmove` `{ passive: false }`)

### 2. 문제 정의

완독 후 아이가 할 수 있는 것이 `/library`로 돌아가는 것뿐이다
(`app/(reader)/book/[id]/celebrate/page.tsx:171-176` — 링크 1개). 방금 읽은 책의 언어를
한 번 더 만나는 접점이 없다.

동시에 **지금은 기록을 붙일 수 없는 시점**이다(§1.4). 그래서 "기록 없이 즐거움만 주는"
최소 파일럿으로 가치를 먼저 검증한다.

## Decision

### 원칙 — 파일럿은 쓰기 경로를 하나도 늘리지 않는다

> **단어카드·퀴즈 파일럿은 DB에 아무것도 쓰지 않는다.** 읽기만 한다.
> 기록이 필요해지는 순간(점수·보상·진도) 그것은 파일럿이 아니라 E-2다.

이 원칙을 명문화하는 이유는 O-10(§1.4)이 미해소 상태이기 때문이다. 쓰기를 늘리지 않으면
경합 결함을 상속하지 않고, `reading-session.ts` 무접촉 제약(ADR-0059 O-10 `:668-669`)도
자동으로 지켜진다.

### D1 — 파일럿은 **무기록**(no-persistence)이다

퀴즈 점수·정답률·진행 상태를 **DB에 일절 저장하지 않는다.** 세션 내에서 표시하고 폐기한다.

- 신규 테이블 **0건**. 기존 테이블 컬럼 추가 **0건**. INSERT/UPDATE **0건**
- 새로고침·이탈 시 결과는 사라진다. 이것은 결함이 아니라 **파일럿의 정의**다
- 기록·보상·테이블 신설은 **O-10(큐 J) 해소 후 E-2로 이연**한다(§Out of Scope)

### D2 — 대상은 `book_text` 보유 858권. GDL 464권은 **조용히 미표시**

Book Dash 190 · ASb 527 · Bloom 141 = **858권**에서만 진입점을 렌더한다.

GDL 464권에서는 **진입점 자체를 렌더하지 않는다.** 안내 문구·비활성 버튼·"준비 중" 표시
전부 두지 않는다.

**선례**: 오디오 배지가 동일하게 동작한다 — 오디오가 없는 책은 배지를 렌더하지 않을 뿐
설명하지 않는다(`app/showcase/showcase-book-card.tsx:70` `{book.hasAudio ? … : null}`).
없는 기능을 설명하면 아이에게는 "못 하는 것"의 목록이 된다.

GDL 텍스트 확보는 **큐 F(O-9 GDL 파서 수정)와 묶어** 후속 처리한다.

### D3 — 진입은 celebrate 화면 **내부**의 선택 진입이다

`app/(reader)/book/[id]/celebrate/page.tsx`의 `CelebrateRewards`(`:164-169`)와
`/library` 링크(`:171-176`) **사이**에 선택 진입 요소를 둔다. 문구 예: "단어 놀이 해볼까?"

**`lib/book/reading-session.ts`는 건드리지 않는다.**

- `:254` 완독 redirect 대상 **무변경**
- `:238-240` "`redirect()`는 `NEXT_REDIRECT`를 throw하므로 반드시 try-catch 밖에 둔다"
  구조 **무접촉**
- ADR-0059 O-10 `:668-669`의 "베타 전 `reading-session.ts` 수정 금지" 자동 준수

**선택 진입이지 강제가 아니다.** 아이가 무시하고 `/library`로 갈 수 있어야 한다 —
완독의 성취감이 숙제로 바뀌면 안 된다.

### D4 — 단어카드는 **런타임 추출**. 탭하면 word marks로 발음 재생

- 해당 책 `book_text.text`에서 **요청 시점에 추출**한다. 사전 계산 테이블 **없음**
- 규칙: **불용어 제외 + 페이지 내 빈도 기준** (구체 규칙은 §단어 선정 규칙 초안)
- 카드 탭 시 `book_audio.marks_path`의 word marks에서 해당 단어 구간을 찾아
  **그 구간만 재생**한다

**재사용 자산**(§1.2) — 신규 파이프라인 아님:
`audio-manifest.ts:55`·`:73` `marksUrl` / `audio-reader.tsx:123-145` `parseMarks()` /
`highlighted-text.tsx:22-31` `WordMark { time, value, start, end }`

`WordMark.time`은 재생 위치(ms), `start`/`end`는 정규화 텍스트 내 오프셋이다. 구간 재생은
`time`으로 seek하고 **다음 mark의 `time`에서 정지**하는 방식을 제안한다(§미해결 쟁점 Q3).

### D5 — 퀴즈는 **탭 기반 4지선다**

- **드래그 미사용**(§1.5 — 사용 사례 0건, 자체 구현 부담)
- **외부 라이브러리 추가 0건** — Hard Rule 11(PLAN.md 미명시 라이브러리 임의 추가 금지).
  애니메이션은 기존 선례대로 CSS transition + `requestAnimationFrame`으로 처리
  (`celebrate-rewards.tsx:29` 선례)
- 정답/오답은 **색 + 아이콘 + 텍스트 병기**. 색만으로 전달하지 않는다
  (`docs/design-system.md:484` — "정보를 색만으로 전달하지 않는다")

### D6 — 자녀 0명에게도 **노출**한다 (ADR-0064 Amendment 대상)

무기록(D1)이므로 **자녀 단위 데이터를 쓰지 않는다** → ADR-0064 `:99-101`의 판정 기준
("자녀 단위 데이터를 쓰는가")에 **해당하지 않는다** → 기록계 기능이 아니다 → 숨기지 않는다.

ADR-0064 `:99-101`이 예외에 Amendment를 요구하므로, 본 ADR에 Amendment 초안을 함께 둔다
(§ADR-0064 Amendment 초안).

**다만 실질 도달 가능성은 낮다.** 진입점이 `/celebrate`인데, 완독은 자녀를 요구하고
(ADR-0064 D4 완독 버튼 자녀 0명 미렌더) `/celebrate`는 자녀 0명이 **애초에 도달 불가**다
(ADR-0064 `:203`). 즉 D6은 **현재로서는 이론적 판정**이며, 진입점이 celebrate 밖으로
확장될 때(E-2) 실효를 갖는다. 이 비대칭을 §미해결 쟁점 Q6에 남긴다.

## 파일럿 사용자 흐름

```
① 완독            /book/[id]/read 에서 "다 읽었어요"
                  → completeReadingSession (무변경) → redirect (무변경)
                          ↓
② celebrate       /book/[id]/celebrate
                  별 3개 · 포인트 카운터 · 배지 (기존, 무변경)
                          ↓
③ 선택 진입       "단어 놀이 해볼까?"  ← D3 신규
                  · book_text 보유 858권에서만 렌더 (D2)
                  · 무시하고 "내 책장으로" 가능 (강제 아님)
                          ↓
④ 단어카드        해당 책 본문에서 런타임 추출한 단어 N장 (D4)
                  · 카드 탭 → word marks 구간 발음 재생
                  · 넘기기: 탭 기반 (드래그 없음)
                          ↓
⑤ 4지선다 퀴즈    탭 기반 M문항 (D5)
                  · 정답/오답 = 색 + 아이콘 + 텍스트
                          ↓
⑥ 세션 내 결과    "3개 중 2개 맞았어요" 수준의 즉시 표시
                  · DB 저장 0건 (D1) · 포인트·배지 미지급
                          ↓
⑦ 종료            /library 로 이동 (기존 링크 재사용)
```

**전 구간에서 DB 쓰기 0건**이다. ①②는 기존 코드 그대로이며 ③~⑦이 신규다.

## 단어 선정 규칙 초안

> **아래 수치는 전부 워커 제안값이다.** 팀장 승인 또는 파일럿 실측으로 확정한다.

### 불용어 방침

- **자체 상수로 관리한다** — `lib/wordplay/stopwords.ts`(경로 제안) 안에 배열 리터럴로 둔다.
  외부 불용어 라이브러리를 추가하지 않는다(Hard Rule 11)
- 대상: 관사·전치사·대명사·be동사·조동사·접속사 등 기능어. 3~7세에게 카드로 보여줄 가치가
  없는 단어들
- **제안 규모: 80~120개.** 영어 표준 불용어 목록(약 170개)보다 **작게** 잡는다 — `run`,
  `big`, `eat` 같은 쉬운 내용어가 실수로 걸러지면 파일럿의 재미가 줄기 때문이다
- 판정 리터럴은 이 파일 **한 곳에만** 둔다(오디오 배지 판정을
  `selectReaderAudioBookIds` 한 곳에 모은 것과 같은 원칙)

### 후보 단어 수

| 항목 | 제안값 | 근거 |
|---|---|---|
| 카드 최소 | **4개** | 4지선다 1문항의 오답 3개를 같은 책에서 뽑으려면 최소 4개 필요 |
| 카드 최대 | **8개** | 3~7세 집중 시간. 완독 직후의 덤이지 학습 과제가 아니다 |
| 퀴즈 문항 수 | **3문항** | 카드 수와 무관하게 고정. §미해결 쟁점 Q1 |
| 단어 최소 길이 | **3자** | `a`, `is` 등 제외 (불용어 목록과 이중 방어) |
| 단어 최대 길이 | **10자** | 카드 1장에 16px 이상으로 들어가는 상한(§디자인 제약) |

### 후보 부족 시 처리 (짧은 책)

페이지당 중앙값 15단어(§1.1)이므로 **3~4페이지짜리 책에서는 불용어 제외 후 4개 미만이
남을 수 있다.**

**제안**: 유효 후보가 **최소 4개 미만이면 진입점을 렌더하지 않는다.** D2의 GDL 처리와
동일하게 **조용히 미표시**한다 — 진입했는데 카드가 1장뿐인 경험보다 낫다.

- 판정 시점은 celebrate 렌더 시. `book_text` 조회 1회로 후보 수를 세고 진입점 표시 여부를
  결정한다
- 이 판정으로 **858권 중 몇 권이 실제 제외되는지는 미실측**이다. §검증 계획 V4에서 측정한다

### 빈도 계산 범위

**책 전체 합산**을 제안한다(페이지별이 아니라). 페이지당 15단어로는 빈도 차이가 거의 나지
않아 사실상 무작위가 되기 때문이다. 동점 시 **먼저 등장한 단어** 우선(안정 정렬 —
같은 책은 항상 같은 카드가 나와야 재실행 시 혼란이 없다).

## ADR-0064 Amendment 초안 (D6 근거)

ADR-0064 `:99-101`이 "예외를 두려면 본 ADR에 Amendment를 남긴다"고 요구하므로 아래 문안을
제안한다.

> **Amendment #1 (2026-08-20, ADR-0065 D6) — 무기록 기능은 기록계가 아니다.**
>
> §원칙의 판정 기준은 "**자녀 단위 데이터를 쓰는가**"다. 단어카드·퀴즈 파일럿
> (ADR-0065 D1)은 DB에 아무것도 쓰지 않으므로 이 기준에 해당하지 않는다. 따라서
> **기록계 기능이 아니며 자녀 0명에게 숨기지 않는다.**
>
> 이 예외는 **무기록인 동안에만** 유효하다. ADR-0065 E-2에서 점수·보상을 저장하는 순간
> 자녀 단위 데이터를 쓰게 되므로 **자동으로 기록계 기능이 되고 §원칙의 일괄 숨김 대상으로
> 복귀한다.** 그때 본 Amendment는 실효한다.

**★ ADR-0064 원본 파일은 본 작업에서 수정하지 않았다.** 위 문안은 초안이며,
`docs/adr/0064-child-optional-registration.md`에 실제로 반영하는 것은 **별도 지시서
항목**이다(본 ADR이 `Accepted`로 승격된 뒤 수행).

## Alternatives

### (a) 파일럿부터 점수를 저장한다 — **기각**

O-10(§1.4)이 미해소다. `reading_sessions` 확장은 경합 결함을 그대로 상속하고, 신규 테이블은
O-10 해소 전에 자녀 단위 쓰기 경로를 하나 더 늘린다. **파일럿의 목적은 가치 검증이지
데이터 축적이 아니다** — 기록은 가치가 확인된 뒤에 붙여도 늦지 않다.

### (b) 완독 직후 퀴즈를 **강제** 진입시킨다 — **기각**

`reading-session.ts:254` redirect 대상을 바꿔야 하는데, `:238-240`이 "`redirect()`는
`NEXT_REDIRECT`를 throw하므로 반드시 try-catch 밖" 구조를 못박고 있어 위험하다. 게다가
O-10의 "베타 전 `reading-session.ts` 수정 금지"에 정면으로 걸린다. 무엇보다 **완독의
성취감이 숙제로 바뀐다.**

### (c) GDL에 "준비 중" 안내를 표시한다 — **기각**

없는 기능을 설명하면 아이에게는 "못 하는 것"의 목록이 된다. 오디오 배지가 이미 조용한
미표시를 선례로 확립했다(D2). 화면마다 말이 달라지는 것을 막는 것이 ADR-0064 §원칙의
취지이기도 하다.

### (d) 사전 계산 단어 테이블을 먼저 만든다 — **미채택(E-2 이연)**

런타임 추출의 비용이 실제로 문제가 되는지 **아직 모른다**. 페이지당 15단어 · 책당 수십
페이지면 추출 대상이 작다. 조기 최적화이며, 테이블 신설은 Hard Rule 8(ADR 선행)을 부른다.

### (e) 드래그 앤 드롭 퀴즈 — **미채택**

3~7세에게 드래그가 탭보다 직관적이라는 근거를 갖고 있지 않다. 오히려 유아 소근육 기준으로는
탭이 안전하다(§6.5가 44px 하한을 두는 것과 같은 이유). 사용 사례 0건 + 라이브러리 추가 시
Hard Rule 11 위반이므로 자체 구현 부담까지 진다.

## Consequences

### 좋아지는 것

- 완독 후 접점이 생긴다 — 방금 읽은 책의 단어를 한 번 더 만난다
- **쓰기 경로가 늘지 않는다.** O-10 결함을 상속하지 않고, `reading-session.ts` 무접촉
- 이미 만들어 둔 word marks 자산(10,476건)이 두 번째 용처를 얻는다
- 가치 검증을 **스키마 변경 없이** 할 수 있다 — 실패해도 되돌릴 것이 화면뿐이다

### 나빠지거나 늘어나는 것

- **결과가 남지 않는다.** 아이가 "어제 몇 개 맞았지?"를 물으면 답할 수 없다. 이것은 D1의
  의도된 대가이며 E-2에서 해소한다
- 활성 카탈로그의 **35%(GDL 464권)에서 기능이 없다.** 큐 F 전까지 해소 불가
- celebrate 화면이 길어진다 — 44px 하한 때문에 공간 압박이 있다(§디자인 제약)
- 카드 UI를 신규 제작해야 한다. `components/ui/`에 Card 프리미티브가 없고 기존 카드는 이미
  3벌 중복이라, **4벌째를 만들지 공용화할지** 판단이 필요하다(§미해결 쟁점 Q5)

### 변하지 않는 것

- 완독 흐름·보상 적립·redirect 구조 (`reading-session.ts`·`rewards.ts` 무접촉)
- DB 스키마 (테이블·컬럼·제약 신설 0건)
- 오디오 리더·하이라이트 동작 (자산을 **읽기만** 하고 수정하지 않는다)
- 라이선스·어트리뷰션 표시 (Hard Rule 1~5 무관)

## Open Questions (구현 지시서에서 확정)

- **Q1 — 퀴즈 문항 수를 몇으로 할 것인가.** 제안 3문항. 카드 수(4~8)와 연동할지 고정할지.
  문항이 카드보다 많으면 같은 단어가 반복된다.
- **Q2 — 오답 선택지를 어떻게 생성할 것인가.** 후보: ⓐ 같은 책의 다른 단어(문맥 일관, 단
  짧은 책에서 고갈) ⓑ 전체 코퍼스에서 무작위(고갈 없음, 단 난이도 널뜀) ⓒ 길이·첫글자가
  비슷한 단어(변별력 높음, 단 계산 비용). **본 파일럿의 가장 큰 미결 항목이다.**
- **Q3 — 단어 구간 재생의 종료 지점.** `WordMark.time`으로 seek한 뒤 **다음 mark의
  `time`에서 정지**하는 방식을 제안했으나, 마지막 단어에는 다음 mark가 없다. 페이지 오디오
  끝까지 재생할지 고정 길이로 자를지.
- **Q4 — 퀴즈 문제 유형.** "단어 → 뜻"인가 "발음 → 단어"인가 "그림 → 단어"인가.
  3~7세는 문자 해독 능력이 개인차가 크므로 **발음 기반이 유리할 수 있다**(word marks 자산과도
  맞는다). 뜻 기반은 한국어 번역이 필요해 범위를 넘는다.
- **Q5 — 카드 컴포넌트를 신규로 만들 것인가 공용화할 것인가.** 기존 3벌 중복(§1.5)에
  4벌째를 더하는 문제. 공용화는 파일럿 범위를 넘길 수 있다.
- **Q6 — D6의 실효 시점.** 자녀 0명은 `/celebrate`에 도달 불가하므로(ADR-0064 `:203`)
  D6은 현재 이론적 판정이다. 진입점이 celebrate 밖으로 확장되는 E-2 전까지 이 비대칭을
  어떻게 문서에 유지할 것인가.
- **Q7 — 후보 부족(4개 미만) 도서가 몇 권인가.** V4에서 실측한다. 이 수치가 크면 최소값
  4를 낮추거나 오답 생성 방식(Q2)을 ⓑ로 강제해야 한다.
- **Q8 — 재진입 시 같은 단어가 나오는가.** 안정 정렬을 제안했으나(§단어 선정 규칙),
  같은 책을 다시 읽었을 때 같은 카드가 나오는 것이 지루할지 안정적일지 판단이 필요하다.
