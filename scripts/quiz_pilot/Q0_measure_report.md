## 0. 행수 정합 검증 (수치를 쓰기 전에 먼저 한 일)

과거 "25행 차" 이슈를 되풀이하지 않기 위해, 집계 전에 **수집 행수가 진짜인지** 먼저 확인했다.
PostgREST `range()` 페이지네이션은 **전순서(total order)가 없으면 행이 새거나 겹친다.**

| 테이블 | `count=exact` | 페이지네이션 수집 | 판정 |
|---|---:|---:|---|
| `books` | 4,273 | 4,273 | 일치 |
| `book_text` | 9,496 | 9,496 | 일치 |
| `book_audio` | 10,476 | 10,476 | 일치 |

추가로 `book_text`를 정렬키 2종(`order(book_id)` / `order(book_id,page_index)`)으로 각각
재수집해 대조했다 — **결과 집합 동일, 중복 0, 누락 0**.
근거 스크립트: `scripts/quiz_pilot/_verify_counts.py`

> 이 절이 아래 모든 수치의 신뢰 근거다. 정합이 깨졌다면 수치를 내지 않고 STOP했을 것이다.

## 1. 모집단 정의 — "활성 858권"은 실측으로 확인됨

지시서가 준 858이라는 수치를 그대로 쓰지 않고 로컬에서 재검산했다. **일치한다.**

| 조건 | 권수 |
|---|---:|
| `books` 전체 | 4,273 |
| `is_active = true` | 1,322 |
| 활성 ∩ `book_text` 행 보유 | **858** |
| 활성 ∩ 페이지 오디오(`kind='page'`, `voice='danielle'`) 보유 | **858** |
| 위 둘 다 만족 | **858** |

**세 집합이 정확히 같은 858권이다.** 즉 "텍스트가 있는 활성 책 = 오디오가 있는 활성 책"이다.

등가 SQL:
```sql
SELECT count(*) FROM books b
WHERE b.is_active
  AND EXISTS (SELECT 1 FROM book_text t WHERE t.book_id = b.id)
  AND EXISTS (SELECT 1 FROM book_audio a
              WHERE a.book_id = b.id AND a.kind = 'page' AND a.voice = 'danielle');
-- 858
```

ADR-0065 D2(`docs/adr/0065-word-card-quiz-pilot.md:162`)의 "Book Dash 190 · ASb 527 ·
Bloom 141 = 858권"과 **소스별 내역까지 정확히 일치**한다.

### ⚠️ GDL은 모집단에 0권이다

지시서는 소스별 분포에 `gdl`을 포함해 달라고 했으나, **GDL은 활성 464권 전부가
`book_text` 0행**이라 858 모집단에 한 권도 들어오지 않는다. 아래 모든 표에서 GDL 행이
비어 있는 것은 누락이 아니라 실측 결과다(ADR-0065 D2의 "GDL 464권 조용히 미표시"와 동일 상태).

| source | 활성 권수 | 모집단(858) 기여 |
|---|---:|---:|
| african_storybook | 527 | 527 |
| gdl | 464 | **0** |
| book_dash | 190 | 190 |
| bloom | 141 | 141 |
| 합계 | 1,322 | 858 |

### 부수 관찰 (이번 범위 밖, 기록만)

`books.has_audio = true`는 **161권**뿐인데 실제 페이지 오디오 보유는 858권이다.
플래그가 실태를 따라오지 못한 상태로 보인다. 본 개편은 이 플래그를 쓰지 않으므로

## 2. STEP 1-1 — `book_text.image_url` 페이지별 상이 여부

책별로 (총 페이지 수, DISTINCT image_url 수, image_url NULL 페이지 수)를 집계했다.

등가 SQL:
```sql
SELECT b.source_platform, b.source_id,
       count(*)                              AS pages,
       count(DISTINCT t.image_url)           AS distinct_images,
       count(*) FILTER (WHERE t.image_url IS NULL) AS null_image_pages
FROM books b JOIN book_text t ON t.book_id = b.id
WHERE b.is_active
GROUP BY b.id, b.source_platform, b.source_id;
```
집계 구현: `scripts/quiz_pilot/measure_q0.py:97-121`

**분류 정의** — A) `distinct = pages` 이고 NULL 0면 / B) `distinct ≥ 2`이나 A가 아님 /
C) `distinct ≤ 1` (단일 이미지 또는 NULL 다수)

| source | 권수 | A 전 페이지 상이 | B 일부 중복 | C 단일/NULL |
|---|---:|---:|---:|---:|
| african_storybook | 527 | 264 | 263 | **0** |
| book_dash | 190 | 190 | 0 | **0** |
| bloom | 141 | 140 | 1 | **0** |
| gdl | 0 | — | — | — |
| **합계** | **858** | **594** | **264** | **0** |

**C 분류가 0권이다.** 삽화가 단일 이미지뿐이거나 NULL이 지배적인 책은 858권 중 하나도 없다.
이것이 세 문항 모두의 출제 가능 권수가 높게 나오는 근본 이유다.

부가 실측:
- `image_url`이 NULL인 페이지를 **하나라도** 가진 책: **30권**
- 전 페이지가 NULL인 책: **0권**
- 페이지 수: 최소 3 · 중앙값 12 · 최대 55
- B 분류 264권의 `distinct/pages` 비율 중앙값 **0.90** — 중복은 대체로 한두 면 수준이다

**문항 ②에 대한 결론**: 표본 범위에서 페이지 번호 유출 위험은 **관측되지 않았다.**
따라서 지시서가 요구한 두 시나리오(페이지 번호 인쇄 소스 포함/제외)는 **같은 값**이 된다.

### 3.2 ⚠️ 예상 밖 발견 — Book Dash 삽화에는 **본문 문장이 인쇄**되어 있다

페이지 번호를 찾다가 더 큰 것을 발견했다. **Book Dash 일부 계보는 삽화 이미지 자체에
그 페이지의 본문 문장이 그대로 찍혀 있다.**

예: `book_dash__moms-hands__p00.png` 안에 "Mom holds me close. / Her hands move. / I smile."이
인쇄돼 있고, 이는 `book_text.text` 값과 동일하다.

**이것은 페이지 번호보다 문항 ①·③에 직접적인 위협이다:**
- **문항 ③(그림 보고 문장 찾기)** — 정답 문장이 그림 안에 인쇄돼 있으면 **정답 완전 유출**
- **문항 ①(문장 듣고 그림 찾기)** — 듣지 않고 글자만 봐도 맞출 수 있다.
  단, 대상이 만 3~7세라 읽기 능력에 따라 유출 강도가 다르다
- **문항 ②(먼저 나온 장면)** — 페이지 번호가 아니므로 순서 유출은 없다. **무해**

### 3.3 계보 판별 — UUID slug vs kebab slug

Book Dash 190권은 slug 형태로 두 갈래다. 표본이 계보와 **예외 없이** 갈렸다.

| 계보 | 권수 | 표본(텍스트 있는 면) | 삽화 내 문장 인쇄 |
|---|---:|---:|---|
| kebab slug (`moms-hands` 등) | **151** | 13면 | **13/13 인쇄됨** |
| UUID slug (`9c9e6e52-…` 등) | **39** | 6면 | **0/6 (미인쇄)** |

검증 표본은 최초 15면 + 계보 확인용 추가 5면(`EXT_*`) = 20면이다.
`unathi-…__p13`은 `book_text.text`가 빈 문자열인 면이라 판정에서 제외했다(반례 아님).

**한계 — 이 151/39는 전수가 아니라 표본 기반 추정이다.** 20면 전부가 계보와 일치했으나,
190권 전수 확인은 하지 않았다. 문항 ①·③을 확정하려면 **book_dash 190권 전수 판정이
선행되어야 한다.** ASb 527권·Bloom 141권은 표본 30면 전부 문장 미인쇄였다.

## 5. 조건 정의와 실제 데이터 구조의 정합성

지시서 조건이 실제 구조와 맞지 않는 지점은 **없었다.** 확인한 사항:

- `book_text`에 `image_url` 컬럼이 실재한다(`lib/book/audio-manifest.ts:284-289`에서
  `page_index, text, image_url`을 함께 SELECT). 이미지 조립이 아니라 **원본 URL 그대로**다
  (ADR-0057 D2 — `lib/book/audio-manifest.ts:13`)
- 페이지 오디오 판정은 `kind='page'` + `voice='danielle'`이 정본이다
  (`lib/book/audio-manifest.ts:104` `DEFAULT_READER_VOICE`, `:321` kind 필터).
  표지는 `kind='cover'`로 구분되며 `page_index=0`은 placeholder라 본문 첫 면과 구분되지 않는다
- `page_index`는 0-based(ADR-0046 D2)
